Kamergotchi Online

Deze browser ondersteunt geen JavaScript of dit is uitgeschakeld. JavaScript is nodig om Kamergotchi Online te kunnen spelen.

Dit bericht is ook kort te zien als het spel wordt geladen. Bij moderne browsers is het ook mogelijk dat extensies JavaScript blokeren, voorbeelden van dit soort extensies zijn NoScript (blokkeert alle scripts en actieve inhoud) en GNU LibreJS (blokkeert scripts met bepaalde functies die niet expliciet open source zijn). Om Kamergotchi Online te gebruiken, heeft deze website in dat geval toestemming nodig om scripts uit te voeren.

Ondersteunde webbrowsers:

Standaardversie

Kamergotchi Online werkt met bijna iedere webbrowser uit de 21e eeuw die JavaScript ondersteunt.

Hieronder volgt een lijst met de oudste browser-engines (met bijbehorende browser en jaartal) die werken. Er is gegaan voor een lijst met browser-engines in plaats van browsers omdat dat korter is: Zo gebruiken latere versies van Netscape, de browser van de Mozilla-Suite en Firefox onder water allemaal de Gecko-engine. Als er dan een werkt, werkt de rest vanaf dat punt waarschijnlijk ook.

  • Trident (Internet Explorer 5.0, 1999)
  • Gecko 0.6 (Netscape 6.0, 2000)
  • KHTML 3.0.3 (Konqueror 3.0.3, 2002)
  • Webkit 85 (Safari 1.0, 2003)
  • Presto 1.0 (Opera 7, 2003)

Legacyversie

Speciaal voor de browsers van de 20e-eeuw bestaat er ook een legacyversie. Deze is beperkter, maar ondersteunt alles terug tot de geboorte van JavaScript. Hieronder volgt een lijst met werkende browsers:
  • Netscape Navigator 2 (1995)
  • Internet Explorer 3 (1996)
  • Opera 3 (1997)
